# 用户验收清单 · v0.2(fixed)

本次 For-Codex 分支上传已获得授权；以下为使用者人工复查表。这里的复选框不代表自动测试结果；请按实际体验填写，不适用的项目写明原因。

环境：Windows 版本____；Codex 版本____；Node.js 版本____；显示器数量/缩放____；全新安装或升级____。

## 安装与启动

- [ ] 校验 ZIP 的 SHA-256 与附带文件一致。
- [ ] 安装前检查通过，安装结束没有错误，版本显示 0.2.0。
- [ ] 打开 Codex 后自动出现，不需要发送消息，也没有常驻空终端。
- [ ] 完全退出并重开 Codex 后仍能出现；旧角色、设置和账本保留。

## 窗口与交互

- [ ] 连续最小化/还原至少 10 次，每次都出现且能点击。
- [ ] 打开另存为后取消，返回 Codex，挂件恢复。
- [ ] 实际保存一个自己的测试文件后，挂件恢复。
- [ ] 拖动、缩放、最大化窗口，挂件位置合理；有多屏时测试跨屏/DPI变化。
- [ ] 点击、拖动吸附、300 ms 翻转、透明区穿透正常。
- [ ] 偶发不显示时，托盘“恢复显示小鲸鱼”能恢复；切回 Codex 也能恢复，无需先手动隐藏。
- [ ] 气泡观看期间后台刷新不闪换随机语，重新进入才更新内容。

## 费用与取消

- [ ] 开启“每轮消耗提示”，运行中取消后仍显示中性费用结算。
- [ ] 取消不说“挤不进去...”或其他趣味文案，也不播放成功音。
- [ ] 金额暂不可确认时显示待记账/未知和可用 token，不冒充零消费。
- [ ] 取消后立即开始下一轮，上一轮消耗提示仍保留。
- [ ] 成功主轮只提示一次；子任务不会反复触发成功音或重复金额。
- [ ] 无需故意大量付费调用验证拥挤；若自然遇到指定报错，记录最终失败/重试/取消各自表现。

## 设置与汇率

- [ ] API 设置没有私有地址、服务商、账号或个人路径回显。
- [ ] 未编辑直接保存，余额查询仍可用；主动编辑/恢复默认只影响对应字段。
- [ ] USD/CNY 切换后余额、预警、预算单位一致，金额显示两位小数。
- [ ] 汇率说明默认收起；点击刷新右侧灰圆 ! 展开，外部点击/Esc 收起。
- [ ] 手动刷新、冷却提示和报价/检查日期显示正常。
