# v0.3 用户验收清单

此清单用于发布后的平台与长期稳定性验证。发布不等于所有设备和场景均已验收。

## 安装与回滚

- [ ] ZIP 完整解压后，Windows“安装插件.cmd”或 Mac 安装入口能运行。
- [ ] 全新安装不需要作者本机路径或配置；可读取自己的 Codex 设置。
- [ ] 首次下载 Electron 的网络要求和报错清楚；安装完成有实际运行验证。
- [ ] 升级保留设置、素材与账本；回滚检查能找到本次私有回执。

## 布局与功能

- [ ] B 版概览/用量/设置三页可用，切换 API/订阅不关闭菜单且保留当前页。
- [ ] 四角打开菜单、窄窗口和不同缩放下不裁切，内容可滚动。
- [ ] 新安装默认右下角；拖动后记忆位置，设置中可重置。
- [ ] 角色、气泡、音效、手感、音量、吸附翻转、资源管理与工坊入口齐全，保存/取消符合预期。
- [ ] API 的预警、预算、汇率、记录、图表和高级接口设置正常。
- [ ] 工坊导入后出现新条目，失败不破坏原素材；只接收支持的 JSON 包。

## 显示与光标（重点）

- [ ] 任务运行、结束和取消后静置观察，挂件不消失或闪跳。
- [ ] 切换应用、最小化/还原、桌面/跟随切换后显示正确。
- [ ] 在 Codex 出现新文字、拖选文字时，无异常白块或光标来回变化。
- [ ] 打开并关闭设置/消费记录窗口后，透明空白处不截获鼠标。
- [ ] Windows 软件合成下按压、拖动、翻转和音效响应可接受。

## 数据口径

- [ ] API 显示金额，订阅显示本轮 token，不混用消费提示。
- [ ] 5 小时与每周额度分开显示，各自重置时间正确；过期或无快照有提示。
- [ ] 在真实订阅账号上完成请求后刷新，记录官方快照可用性；本机 token 不被标成官方剩余额度。
- [ ] 取消提示中性、无成功音；未知金额不显示为零。
- [ ] DeepSeek 峰谷仅对适用的官方端点显示。

## 反馈格式

填写插件构建号、操作系统、显示器数量/缩放、操作顺序、发生时间和频率。复发消失时说明当时是否在前台、是否有弹窗、是否任务刚结束。不公开 API 地址/密钥、认证文件、完整运行回执或聊天截图；截图应裁剪并遮蔽账号与会话。
