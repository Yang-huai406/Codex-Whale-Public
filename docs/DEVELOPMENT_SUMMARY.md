# v0.3 本轮开发摘要

此文档归纳本轮讨论和最终实现，可用作 README 与后续维护素材，不包含原始聊天、截图、录像、私人接口、账号、消费记录或本机路径。

## 目标与最终决定

从 v0.2 fixed 基线升级，保留 [macOS PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 平台分支、来源及署名。Codex 适配维护者为 [Yang-huai406](https://github.com/Yang-huai406)。参考 DSH 各版说明做模块化、自检和功能补充，不整包覆盖已有修复。

比较卡片、分页和迷你条后选用 B 版“概览 / 用量 / 设置”。迁移原控件及保存逻辑，不削减角色、声音、气泡、资源、预警、预算、图表和高级接口功能。顶部切换保留当前页，窄窗口只滚动内容。API 显示金额，订阅显示 token 与分开的 5 小时/周额度窗口；额度快照和本机统计分别解释。

加入独立桌面、默认右下角及重置、三种手感和合成音效、本地 JSON 创意工坊。DeepSeek 峰谷只用于识别出的官方端点。详细功能见 [B 版对照](DASHBOARD-B.md)。

## 显示与输入问题

1. 已确认早期静止闪动的一条原因是短暂心跳延迟被误判为宿主消失。现将健康诊断与隐藏操作分离。
2. 修复尺寸同步的旧坐标写回、加载中重复刷新、模式切换状态及销毁窗口的迟到 IPC。
3. 暂停挂件后，白块和光标异常暂时消失。随后使用 Windows 原生区域排除空白覆盖，并去除整屏灰色遮罩与模糊。
4. 光标再次出现后，发现输入判断仍把 dialog/mask 当作整窗可点击，现只命中实际卡片。
5. 再次消失时，进程、页面与原生区域正常，没有隐藏或重启记录；截图附近又出现，提示合成链路可能参与。Windows 挂件改用软件合成作为可回滚兼容措施。
6. 增加采样前不抬高窗口、不重绘的实际屏幕像素测试，避免测试本身掩盖问题。窗口缩小时直接提交合法位置，不经过屏幕外坐标。

上述内容区分已确认缺陷与兼容措施；最新构建仍待用户日常验收，不能宣称所有设备上的偶发问题均已根除。

## 隐私与计费规则

已有私密配置不回显，未填写时保留原值。取消保留中性消耗、不播放成功音；明确拥挤失败才提示“挤不进去...”。未知/待记账不能显示成零，API 观测差额不是精确逐请求账单，本机 token 不是官方剩余额度。

分发包不含作者数据、运行缓存、个人回执和聊天媒体；保留公开维护者、上游版权和第三方许可。Mac 实机、真实订阅账号、长期显示稳定性等待验收。CC Switch 路由和壁纸层嵌入未实现，本地工坊不是在线市场。
