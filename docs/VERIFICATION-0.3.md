# v0.3 验证记录

## 已有证据

当前运行代码在 Windows 上完成：

- 223 项自动测试：配置与隐私、账本/通知、子任务去重、导入事务、IPC、可见性与窗口区域等。
- 真实 Electron 界面回归：B 版完整设置清单、API 预算和历史、订阅合成快照、四角/360×320 布局、拖动与气泡、透明背景穿透。
- 软件合成下 16 次桌面/跟随切换及 30 秒静置，未新增空闲重显。
- 不在采样间抬高窗口或调用 capturePage 的 12 次实际屏幕像素采样，最低角色匹配率约 99.4%；包括消费气泡收起，未新增重显或空闲重绘循环。
- 动画/翻转/拖动性能回归通过，保持原响应要求和空闲不持续重绘。
- 六轮消费气泡弹出/收起后角色区域仍保留，右下角重置成功。

旧 v0.2 的压力测试仅是历史记录，不作为当前构建的完整证明。测试截图、个人录像、日志和本机回执不放进分发包。

## 不能据此声称的结论

短时测试不能证明偶发消失、白块或光标异常在全部设备上已经根除。Windows 软件合成是兼容措施，不是已证实的唯一根因。Mac 实机、Spaces/多屏/睡眠恢复以及真实订阅账号端到端均待验证；订阅 UI 测试使用合成数据。

## 发行包检查

本次材料整理保持已测试运行代码，更新文档、忽略规则和打包工具。构建脚本会校验依赖、当前文档链接、隐私模式、ZIP 完整性和 SHA-256；分发副本剥离非必要媒体元数据，不改像素/音频帧。具体文件清单与散列以随包的 release-manifest.json 为准。

从源码包重新解压后运行：

```sh
node scripts/check-package.mjs
node --test tests/*.test.mjs
```

Windows 安装预检：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1 -CheckOnly
```

预检不是在另一台设备上的全新安装证明。完整验收按 [用户测试清单](USER_TEST_CHECKLIST.md) 执行。
