# v0.3(fixed) 验证记录

本记录对应插件构建 `0.3.0+codex.20260929173027`。显示名称更新为 **v0.3(fixed)** 不改变运行代码构建号。用户已明确授权本次 `For-Codex` 分支、tag 与 Release 发布；使用标签 `codex-v0.3.0-fixed.2`，Release 名称 `Codex-v0.3(fixed)`。以下验证范围与未完成验收项目不因发布授权而改变。

## 本构建已有证据

- **238 项单元测试通过**：覆盖既有配置、隐私、用量和窗口状态逻辑，并包含绘制生命周期、延迟子动画、快速重开、隐藏/移除清理、悬停延迟取消和点击隔离。
- **16 次真实 Windows 原生区域采样**：使用 `GetWindowRgn` / `GetRegionData` 检查气泡关闭中途及快速重开。关闭类移除后仍保留动画需要的绘制边界，动画结束后收缩。
- **菜单可达性与穿透**：慢速、快速以及角色翻转后的跨缝隙移动能够打开菜单；`WindowFromPoint` 确认透明缝隙继续归底层窗口接收，而非扩展挂件点击范围。
- **关闭画面专项检查**：隔离测试窗口上的屏幕图确认气泡完整淡出。该专项临时将测试窗口置顶以观察动画，因此只证明动画裁剪行为，不作为日常跟随层级或长期稳定性的证明。
- **现代 B 版 Electron 审计通过**：现有角色、音效、设置、模式切换、拖动和关闭流程完成回归。使用适配“概览 / 用量 / 设置”的 `tests/desktop-audit-smoke.mjs`。
- **本机安装验证**：完整安装器的运行构建核验和渲染器就绪检查完成；回滚预检可识别对应备份。安装与回滚回执属于用户本机资料，不进入公开包；回滚预检不等于在另一台设备上实际执行了回滚。

专项机制及验收重点见 [绘制生命周期与悬停修复](SURFACE-LIFECYCLE-FIX.md)。早期版本的测试数量、模式切换观测和屏幕采样只属于历史记录，不并入本构建的验证证据。

## 已知测试限制

旧 `scripts/smoke-desktop.mjs` 会在默认“概览”页查找隐藏“设置”页中的“角色”文本，因而触发布局断言。修复前基线中的同一测试和 B 版布局也存在相同不适配；它尚未迁移到当前页面结构。此项如实记录为旧测试不适配，不写成“全部测试脚本通过”，也不将它混同于本次动画修复的新增回归。

页面 `capturePage()` 或等待全部动画结束后的截图，不能单独证明 Windows 原生窗口在关闭中途没有裁边。本次动画证据同时检查真实原生区域与专项屏幕图。

## 尚待用户验收

- Windows 日常跟随中的长期显示稳定性、多显示器与不同缩放，以及最小化、还原、睡眠恢复。
- 原场景中的完整淡出、慢速移动到菜单按钮、透明空白点击与文字拖选。
- macOS 实机，含 Apple Silicon / Intel、Spaces、多屏及睡眠恢复。保留 [PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 不等于完成 Mac 实机验收。
- 真实订阅账号的额度快照和端到端刷新。合成快照验证的是界面及口径，不是官方账号实测。
- 新打包 ZIP 的完整解压、用户环境安装、升级保留和必要时的回滚。

短时验证不能证明偶发消失、白块或光标异常已在所有设备根除。Windows 软件合成和遮挡设置仍按兼容措施描述；不将某次专项通过解释为所有显示问题的唯一根因已确定。

## 包与复验

发布附件文件名为：

- `api-balance-whale-v0.3(fixed).zip`
- `api-balance-whale-v0.3(fixed)-source.zip`
- 两个 ZIP 各自的 `.sha256` 文件、`release-manifest.json`，以及记录成品复验结果的 `verification-report.json`

文件完整性、实际构建内容及散列以本次重新生成的清单为准。材料整理不得通过修改展示名称伪造一次新运行版本，也不得把旧报告改名当成新测试。测试日志、截图、录像和个人回执不放入分发包。

从源码包完整解压后可运行：

```sh
node scripts/check-package.mjs
node --test tests/*.test.mjs
```

Windows 安装预检：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1 -CheckOnly
```

这些命令分别检查包与自动测试，不替代另一台设备上的真实安装。用户试装与反馈继续按 [用户测试清单](USER_TEST_CHECKLIST.md) 执行；本次已获发布授权，但未完成的 Mac、长期稳定性和真实订阅验收仍保持待验证。
