# B 版分页与功能对照

顶部“API 余额 / Codex 订阅”选择展示模式；下方“概览 / 用量 / 设置”选择页面。切换模式保持菜单和当前页面，不改登录、模型或密钥。顶部始终可见，空间不足时滚动内容区。

无有效保存位置时，第一帧即位于右下角。设置 → 外观与位置 →“位置重置到右下角”可主动重置，后续拖动仍会记忆位置。无穷大或负距离的旧锚点不再用于恢复。

| 页面 | API 余额模式 | Codex 订阅模式 |
| --- | --- | --- |
| 概览 | 当前余额、今日与本轮已观测消费、刷新、接口设置 | 分开的 5 小时与每周额度、各自重置时间与过期状态、本轮 token、刷新与详情 |
| 用量 | 今日与近 7 天消费、预警、预算、全部明细、图表与模型占比 | 本机滚动 5 小时与近 7 天 token，以及输入、输出、缓存、推理分项 |
| 设置 | 完整的角色、声音、气泡、位置、资源与接口设置 | 通用设置完整保留；API 金额专属项随模式隐藏 |

没有快照时明确显示未观测，不用示例填充。订阅百分比不是固定 token 配额；本机 token 不含其他设备，缓存/推理可能已包含在输入/输出中。API 小额大于零但不足显示精度时显示“＜0.01”，未知与待记账不会显示成零。

## 保留的原功能

- 外观与位置：角色选择/导入、大小滑块与数字、滚动条避让及宽度、吸附/翻转自定义、隐藏菜单按钮、桌面/跟随切换。
- 声音与气泡：音效选择/导入与原编辑器、主音量、气泡总开关和完整编辑器、每轮提示及关闭时间、任务结束声音、音效与手感面板及所有事件音量/试听。
- 用量与资源：币种、汇率刷新和说明、资源管理、创意工坊导入/导出/预览/重载、适用时的 DeepSeek 峰谷、订阅详情。
- API 高级设置：自动/自定义接口、字段/换算、配置方案与目录、单模型价格增改删、会话观测开关；继续隐藏已有私密配置。
- API 用量：余额预警、每日预算及提示模板、今日/近 7 天/全部记录、图表、模型占比与原有明细操作。
- 角色点击、拖动、气泡与中性取消提示、托盘和右键入口保持原逻辑。

控件通过移动原节点迁入设置页，未替换为简化表单，原事件与保存逻辑保留。API 用量页直接使用原账本和预算面板，绕开旧整页滑动动画。

## 验证

1. 分别切到 API/订阅，打开三个页签，确认切换后菜单不关闭，选中的页签保留。
2. 将角色放到窗口四角、缩小窗口，确认顶部页签完整，中间内容可滚动。
3. 设置里试角色/音量/气泡/工坊入口；保存后重新打开确认值保留。
4. API 用量页打开预算、更多消费记录和图表；订阅用量页只显示 token 统计。
5. 订阅模式完成或取消一次任务，提示只显示 token；观察两个额度窗口各自的重置时间。
