# Windows 白屏保护与连点音效修复

运行构建：`surface-audio-fix-20261007`；内部版本仍为 `0.4.1`。本构建在 Codex-v0.4(fixed) 上继续修复，以 Codex-v0.4(fixixed) 独立发行，保留旧标签与 Release。

## 问题与范围

| 反馈 | 已证实的代码问题 | 本次修复 |
| --- | --- | --- |
| Windows 0.4.0 短暂白屏、内容被遮挡 | 原版与 fixed 都只相信 setShape 调用及程序缓存，未用真实原生区域约束显示；区域失效仍可能可见 | 常驻独立监控核对完整原生区域，故障撤销显示；恢复必须获得当前窗口/尺寸/形状的验证 |
| 小黄鸭快速点击听感破碎 | 按下和松开共用通道，每次直接 stop；非零波形被硬切，音节频繁重启 | 8ms平滑交叉淡变；90ms内过密声音请求及配对松开合并；不限制实际点击或动画 |

白屏录屏能确认现象，不能独立确定用户设备上的唯一触发点。相关 [#121](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/issues/121) 仍属部分覆盖；本次未关闭上游 issue。连点音效与既有 #187 首音裁切、#197 双重声音不应混为同一根因。

## 窗口保护

Windows 监督器使用常驻线程检查 `GetWindowRgn` 与完整区域并集，而非比较大包围框；多个分离角色、气泡和菜单之间的空白不会误认为有效区域。窗口句柄和进程身份、实例、尺寸代次、形状序号一起验证，迟到的成功结果不能恢复旧窗口。

正常动画更新保持已验证显示，隐藏期间合并布局更新，避免恢复时闪烁和确认饥饿。区域消失在下一轮原生采样撤销；几何不一致允许短暂布局竞争；连续无法验证也有独立期限，不会被不断变化的动画序号无限推迟。监控心跳失联、裁剪失败、渲染无响应也会撤销显示。恢复次数有上限，持续健康30秒后重新开放预算；不通过周期性重启掩盖问题。

25ms采样、100ms稳定窗口及1000ms连续未验证期限是调度参数，不是高负载下的硬实时承诺。原生隐藏使用异步API，不阻塞监督器。渲染进程无响应时会重新加载并重新验证；Electron主线程永久卡死或合法区域内部没有故障事件的合成异常，仍不能保证自动恢复。没有自动结束 Codex 或其它应用进程。macOS不启用Windows区域检查，本次没有Mac实机验收。

## 音效

单击和长按仍使用原先按下/松开素材；长自定义音效松开时及时淡出。超密请求仅合并声音，没有补播队列。过期超过250ms才准备好的交互声丢弃，取消或隐藏后旧解码不复活。静音、隐藏和退出清理当前声音与淡出尾音。任务完成的整组声音和设置试听使用独立通道，不受连点合并影响。

真实小黄鸭素材的按下片段约238ms、松开片段约108ms。离线渲染验证1/5/10/20次每秒：20Hz下两秒操作从80次音源启动降为40次，未出现削波。此数据验证调度和数字波形，不替代实际扬声器、耳机或用户主观试听。

## 用户验收与回滚

1. 安装后检查状态：内部版本 `0.4.1`、构建 `surface-audio-fix-20261007`，Windows `surfaceGuard.verified` 为 true，正常操作没有持续增长的撤销计数。
2. 打开/关闭概览和设置、连续点击角色、最小化还原、拖动窗口及跨显示器移动。正文空白区域应可操作，菜单和气泡保持可见，不出现持续遮挡。
3. 音效分别慢点、快速连点、长按后松开。听感应减少硬切与破碎；极密点击不要求每次都发声，松手后不应排队补叫。单独检查静音、任务提示和自定义音效。
4. 若仍白屏，使用托盘隐藏/退出挂件观察底层是否恢复，记录触发动作与缩放比例。隐藏后白块仍存在时，需要区分宿主自身重绘问题，不能仅凭白色内容判断挂件故障。
5. 本次安装生成独立私有回执，回滚先以该回执 `-CheckOnly` 核对目标，再使用同一回执恢复。前后内部版本可能相同，要同时核对构建标识。恢复旧程序和启动配置，保留最新设置、素材和账本。

隔离测试使用合成服务和专用窗口。真实区域丢失、全窗错误区域、持续动画中静默失败、尺寸变化、合法大卡片、健康预算恢复及渲染无响应均应纳入验收。具体通过数量与测量值以本次本地验证报告为准。
