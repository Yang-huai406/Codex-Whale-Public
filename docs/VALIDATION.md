窗口压力使用独立的真实 Windows owned window、原生文件对话框和实际屏幕像素，Electron 44.3.0、150% 缩放。它验证窗口机制，不等同于逐一覆盖所有 Codex 版本、多显示器组合或所有“保存成功”的业务流程。真实 Codex 已完成新恢复代码及监视器更新，用户随后确认“现在有了”；其他实际体验继续复核；可按 README 对当前软件执行手动验收。

取消结算覆盖：运行中取消仍显示已观测金额；金额未确认显示待记账及 token；取消前发生拥挤不会将取消说成“挤不进去...”；取消后立即开始新一轮仍保留上一轮消耗提示；均不播放成功音。

自动测试使用独立 `WHALE_HOME`、合成凭据和模拟账单响应，不访问真实付费 API。运行 `node --test tests/*.test.mjs` 覆盖账本恢复、余额顺序、汇率、隐私、IPC、媒体输入和桌面状态逻辑。安装器、任务计划和窗口跟随需要 Windows 专项测试。

压力验收至少包括：连续最小化/恢复、另存为打开与取消、保存后返回、快速切换窗口、Codex 退出/重开、监视器重启、并发刷新和网络超时。记录恢复时间、重复进程、孤儿窗口和资源增长；不得仅凭“进程仍在”判定挂件可见。

使用模拟失败/取消/服务繁忙事件检查气泡策略和用量记录。模拟刷新汇率期间按钮连点、成功、失败及旧缓存状态。金额单位与历史账本必须保持一致。

发布前检查：插件清单、package、lock、runtime 与请求 User-Agent 均为 0.2.0；保留上游许可；压缩包只含代码、内置素材、文档、测试和安装工具。排除个人 API 配置、环境文件、聊天和会话、账本、日志、截图、安装回执、备份、缓存和 node_modules。解压包内容清单和 SHA-256 校验应可复查。

最后在独立用户环境验证安装前检查、安装失败回执、卸载及回滚保留数据；真实 Codex 最小化/另存为的最终体验仍需要桌面操作确认。
