## 仍需保留的边界

- 账户扣费不等于某一轮的精确费用，token 不等于官方订阅剩余额度，未知金额不等于零。
- 未确认的单位、额度范围或计费字段不能当作可信余额；没有查询接口时不能凭空得到余额。
- Windows 验证不等于 Mac 实机验收；真实订阅、多设备和长期稳定性仍按已知问题记录。
- 桌面模式是独立浮窗，不是壁纸层嵌入；空白点击关闭是已撤回的设计。
- 保留 [MeteorNOX 上游](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)、MIT 版权、媒体原分发边界、第三方许可证和 [1llysviel 的 macOS PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128)。

## 发布和协作迁移

本次迁移 Git 源码、历史与 9 个相关标签，并另行复制全部 7 个 Codex 历史 Release 及其 38 个附件。GitHub Issue、PR 和讨论仍保留原地址，未代替原作者发帖、关单或删除内容。各版本的原始时间、发布者、来源与附件记录见[发行历史](RELEASE-HISTORY.md)。

当前安装包可从[本仓库最新历史发行](https://github.com/Yang-huai406/Codex-Whale-Public/releases/latest)获取；仓库私有期间仅有权限的用户可访问。迁移副本保留原正文与附件，只在正文前新增迁移说明、原始发布者、发布时间及来源链接。这些发行仍指向历史提交，不包含本次新仓库的文档调整，不是新构建或新版本。GitHub 新建 Release 的发布账号与时间无法回填为原值，因此页面平台记录与正文中的原始发布时间须分开理解。后续在新仓库发布新版本时使用新标签，不移动已发布标签。

上游编号 `#128`、`#177` 等指原仓库编号，不代表新仓库有同号 issue；查阅时以原仓库为准。需要迁移未结事项时应建立链接和对应表，避免冒充原报告者。

对原仓库推送公告、变更分支、关闭或迁移 Issue/PR、改动标签/Release 等重要操作，需要先征询用户。本次没有执行这些操作。新本地工作区把 `origin` 指向新仓库，`upstream` 的推送地址设为禁用占位值，以减少误推送；这是本地设置，不修改远端权限。
