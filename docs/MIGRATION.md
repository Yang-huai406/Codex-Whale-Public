# 本次迁移与验证范围

原始包为 DSH/Cordis 插件。此次沿用原角色与交互资源，将宿主改为 Codex 桌面应用旁的透明辅助窗口。

与前一适配版相比：

1. 移除独立网页界面、HTTP 服务和打开网页的入口。Electron 通过进程内 `whale://widget` 协议加载本地界面资源；这不是浏览器地址或对外服务。MCP 查询与启动监视器使用带认证的 Windows 本地命名管道。
2. Windows 任务计划服务以当前用户普通权限独立运行 PowerShell 监视器，脱离 Codex 的进程树；登录时启动，无执行时限，异常退出可重试。按安装包路径及主进程关系识别 Codex，过滤命令行与后台子进程。透明窗口设置为 Codex 主窗口的所属窗口，跟随移动、缩放与最小化。多任务共享同一挂件。
3. 用图像透明度生成 Windows 窗口命中区域，并在拖动时保持指针捕获；操作区域可以接收点击，空白区域透过点击。原角色、动图、音效、气泡编辑、导入管理、吸附和记账保留。
4. 峰谷模块从默认模板、编辑器、渲染与计费代码中移除，旧配置在备份后迁移。历史金额不重新计算。
5. 金额展示改为固定两位小数，账本计算保留原精度。音频裁剪精度、token 计数不受影响。
6. 原版桌面配置中的角色与位置迁入新的本地界面；旧源的导入只在隔离的本机 Electron 配置中执行一次，不打开网页端口。

## 已验证

- 余额接口、配置隔离、充值/跨日处理、token 去重、缓存与推理 token 计费口径。
- 本地管道鉴权、限制操作范围、无网页监听端口。
- 原图片与音频路由、角色导入/删除/置顶、GIF 图库、音频片段与音效组、设置与气泡持久化。
- 真实 Electron 渲染窗口中的鼠标点击、拖动、菜单和 API 设置；Windows 命中测试；窗口移动/缩放/隐藏/恢复；位置记忆和两位小数。
- 当前电脑的 Codex 窗口识别、所属窗口绑定、实际第三方余额查询。
- 启动修复：计划任务的进程上级为 Windows 服务；挂件关闭后监视器保持运行并自动重建挂件。安装脚本会清理旧启动快捷方式，停用与回滚会删除本插件计划任务。

自动化桌面测试使用隔离数据和模拟宿主状态，不主动重启用户正在工作的 Codex。最终的完整退出/重开验收请按 [操作说明](RESTART-VERIFY-ROLLBACK.md) 执行。未声称穷举所有自定义素材、显示器组合或服务商接口。
