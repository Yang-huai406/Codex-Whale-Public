# macOS 前台宿主层叠与可见性

普通层级的 Codex 激活时可能先覆盖挂件，再由跟随轮询修复顺序。该竞争与原地闪动现象一致；未捕获点击瞬间作为根因的直接证据。

已验证、实际显示的绑定宿主位于前台时，挂件使用 normal + 1。另一个 Codex 窗口或其他应用前置时恢复普通层级。已正确排列的窗口不重复重排，inactive Space 不强制排序；Space 动画期间不修改层级或位置。

AppKit 的窗口显示状态供可见性控制和跟随器使用，避免 Electron 遮挡状态触发不必要的隐藏/恢复。旧原生模块缺少新接口时继续原有判断与排序策略。须重新运行 Mac 安装器编译原生模块。

2026-10-12，本地整合安装经用户手动确认：点击 Codex、交替操作 Codex 和挂件卡片不再闪动，其他应用仍能遮挡挂件。该历史验收针对本地整合版本；本 PR 拆分分支以单元回归和双架构编译另行验证，不宣称分支已重新实机验收。多屏、睡眠唤醒和长期运行未逐项验收。
